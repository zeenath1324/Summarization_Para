# 📝 AI Paragraph Summarizer

## 📌 Project Description
The AI Paragraph Summarizer is a simple Natural Language Processing (NLP) application that converts long paragraphs into short, meaningful summaries. It helps users quickly understand lengthy text by identifying the most important information while preserving the original meaning.

This project uses a pre-trained Transformer model from Hugging Face to generate concise and readable summaries. It provides a user-friendly interface built with Gradio, allowing users to enter text and receive a summary instantly.

## ✨ Features
- Summarizes long paragraphs into shorter text.
- Preserves the main ideas and important information.
- Uses a pre-trained AI summarization model.
- Simple and interactive Gradio interface.
- Easy to use for students, researchers, and professionals.
- Saves time when reading lengthy content.

## 🛠️ Tech Stack
- **Python** – Programming language.
- **Hugging Face Transformers** – AI text summarization.
- **T5 / Transformer Model** – Generates text summaries.
- **Gradio** – Builds the interactive web interface.
- **PyTorch** – Supports model execution.
- **SentencePiece** – Tokenization support.

## 📦 Installation

Install the required libraries:

```bash
pip install "transformers<5.0.0" sentencepiece gradio torch
```

## 🚀 How to Run

1. Clone or download this repository.
2. Install the required dependencies.
3. Open the Python file or Jupyter Notebook.
4. Run the code.
5. Enter a paragraph in the text box.
6. Click the **Summarize** button.
7. View the generated summary.

## 💡 Example

**Input Paragraph:**

Artificial Intelligence is transforming many industries, including healthcare, education, transportation, and business. It enables machines to perform tasks that usually require human intelligence, such as learning, problem-solving, and decision-making. AI helps improve efficiency, reduce manual work, and support better decisions.

**Output Summary:**

Artificial Intelligence transforms industries by enabling machines to learn, solve problems, and make decisions, improving efficiency and reducing manual work.
